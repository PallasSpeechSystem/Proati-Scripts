# Proati-Scripts
Serie de script para melhorar e otimizar máquinas que rodam Windows 11/10 que pertencer a SEDUC.

## Destino dos Scripts

Esses scripts destinam a série de notebooks que são distribuidos nas escolas pela SEDUC. 

### Lista de Notebooks

1. Positivo Sala de Aula:
   1. Positivo Master N1110 (todas as versões).
   2. Positivo Master N1120.
2. Notebooks Avançados/Profissionalizante:
   1. Positivo Master N8480.
   2. Lenovo L14 Gen 2.
3. Notebooks e Computadores Administrativos:
    1. Multilaser Ultra UL150.
    2. Lenovo ThinkCentre M75S.
